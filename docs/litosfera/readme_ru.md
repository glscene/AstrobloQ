## LandScapes
  Этот пакет содержит четыре модуля, демонстрирующих использование GLS.RandomHDS.
Для освоения их следует изучать в следующем порядке:

## ShortLands
*************
  В этом модуле требования для использования класса TGLFractalHDS минимальны.
Также показано, как настроить компоненты GLScene для быстрой работы.
Отображается циклический фрактальный ландшафт и используется
встроенный обработчик событий рельефа земли (внешние текстуры не требуются).
Этот модуль может использоваться в качестве основы для любой программы, использующей этот объект.

##  FracLands
*************
 Этот модуль демонстрирует практически все свойства юнита GLS.RandomHDS.
Вы можете экспериментировать с ними через удобный интерфейс.
Это позволит быстро получить интуитивное понимание того, что
контролирует каждое свойство.

## DuneFighter
***************
  Этот модуль показывает перемещение актёра по повторяющемуся в цикле объекту TGLFractalHDS.   

## FractalArchipelago
*********************
 Модуль показывает как генерировать GLS.RandomHDS «на лету»
с помощью компонента TGLFractalArchipelago.
Прежде чем приступить к работе с TGLFractalHDS следует разобраться в его свойствах и методах.
