# AstrobloQ

Программная платформа AstrobloQ разрабатывается для создания проектов построения виртуальных моделей Солнечной системы, 
Млечного Пути и Вселенной. Обеспечивается возможность разработки стартапов подпрограмм с помощью отечественных систем искусственного интеллекта GigaCode и AI-Assistant. 
Для дальнейшего развития астрофизического и астрометрического направлений AstrobloQ приглашаются программисты [российских астрономических организаций и вузов](https://gitverse.ru/UniverseCETI/GalaxyCETI).

## Virtual UniverseAGI

Визуализация моделей основана на графическом движке [GaLaXy Engine](https://gitverse.ru/glscene/GLXEngine) с поддержкой OpenGL, Directx и Vulkan. 
Сборка путём компиляции C/C++/Delphi проектов выполняется с подключением библиотек открытого исходного кода, в том числе
пакетов визуальных компонентов [GLXEngine](https://github.com/glscene/GLXEngine),
фундаментальной астрометрической библиотеки [SOFA](http://iausofa.org/current_C.html), рекомендованной
[IAU, MAC - Международным Астрономическим Союзом](https://iau.org/).

Моделирование строения, структуры и состава космических объектов выполняется в последовательности PlanetAGI -> StarAGI -> GalaxyAGI -> UniversеAGI. 
AGI - Astro General Intelligence. Интерактивная справка обеспечивает связь управляющих элементов интерфейса с соответствующими темами российской онлайн-энциклопедии Рувики
[Галактика](https://ru.ruwiki.ru/wiki/Галактика)

### Виртуальные астромодели Галактики и Вселенной
 
При построении используются следующие входные данные и основные вычислительные методы: 

- первичными базовыми данными для визуализации являются звёздные каталоги [HYG](https://github.com/astronexus/HYG-Database) и [Gaia DR3](https://www.cosmos.esa.int/web/gaia/data), [NASA exoplanets](https://science.nasa.gov/exoplanets);
- коммуникационные тетраэдральные сети Делоне GalaxyDelaunay генерируются по известным x, y, z значениям положений звёзд в галактической системе координат и по векторам vx, vy, vz их собственных движений с экстраполяцией в прошлое и будущее на шкале -10; 0; +10 Gyr;
- полиэдральные пространственные диаграммы Вороного GalaxyVoronoi, мозаики со звёздами в центральных узлах ячеек, рассчитываются как двойственные графы тетраэдрализации Делоне;
- построение регулярных моделей GalaxyGrid на униформных решётках выполняется по методу NNI, Natural Neighbour Interpolation с учётом влияния в интерполянте астрохарактеристик соседних регионов, за исключением областей войдов GalaxyVoids;
- симуляция формирования строения Галактики на базе подходов N-body, гравитационно взаимодействующих партикулярных кластеров и волновых функций;
- трансформация звёздных популяций имитируется на основе стохастических функций свёртки рождения и гибели звёзд основных спектральных классов согласно диаграмме Герцшпрунга-Рассела;
- при моделировании эволюции небесных тел и конволюции скоплений звёзд применяются операции групповой конволюции спектральных классов звёзд; 
- поиск кратчайшего наиболее безопасного пути между удалёнными звёздами Галактики, задачи коммивояжера, освоения ресурсов и колонизации решаются на 5D графах (x,y,z,t,c) тетрамеша и по алгоритму A* на регулярной решетке GalaxyGrid; 
- для галактической сеточной модели прогнозируется число литосфер, биосфер и техносфер на базе данных обновляемых звёздных каталогов;
- оценка потенциала обитаемости модели GalaxyAGI с техносферами выполняется по диаграмме Вороного 4D и сравнивается с оценкой по эмпирической формуле Дрейка;
- численное решение парадокса Ферми-Циолковского FTP может быть получено как для изолированных техносфер, так и связанных в сеть техносфер, аналогов I и II типа КЦ по шкале академика РАН Н.С.Кардашёва;
- дополнительная информация о звёздном составе и строении невидимой части Галактики, за плотными облаками рукавов и ядром, может быть получена по галактической сети GalaxyCETI;  
- навигация в глобальной модели UniverseCETI, как симуляция коммуникаций в VR/AR, осуществляется между галактиками и процедурно генерируемыми объектами дальнего космоса, звёздами и экзопланетами.
