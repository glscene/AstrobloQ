# AstrobloQ

Программный комплекс AstrobloQ разрабатывается для построения виртуальных моделей Солнечной системы и 
Млечного Пути, и создания цифровой сцены Вселенной. 
Разработка стартапов поддерживается с помощью искусственного интеллекта GigaCode и AI-Assistant. 

## Virtual Universe

Визуализация моделей основана на графическом движке [GaLaXy Engine](https://gitverse.ru/glscene/GLXEngine) с поддержкой OpenGL, Directx и Vulkan. 
Сборка проектов на C/C++/Delphi выполняктся на основе компиляции открытого исходного кода AstrobloQ c внешними библиотеками 
по вычислительной геометрии и астрономии, в том числе астрометрической библиотеки [SOFA](http://iausofa.org/current_C.html), рекомендованной
[IAU, MAC - Международным Астрономическим Союзом](https://iau.org/).

Моделирование строения, структуры и состава небесных тел выполняется в последовательности систем
Земля-Луна -> Солнечная система -> Галактика -> Вселенная. 
Интерактивная справка обеспечивает связь управляющих элементов интерфейса с соответствующими темами российской онлайн-энциклопедии Рувики
[Галактика](https://ru.ruwiki.ru/wiki/Галактика)

## Астромодели Галактики и Вселенной
 
При построении основных моделей применяются следующие данные и методы вычислений: 

- первичными базовыми данными для визуализации являются звёздные каталоги [HYG](https://github.com/astronexus/HYG-Database) и [Gaia DR3](https://www.cosmos.esa.int/web/gaia/data), [NASA exoplanets](https://science.nasa.gov/exoplanets);
- тетраэдральные сети Делоне GalaxyDelaunay генерируются по известным x, y, z значениям положений звёзд в галактической системе координат и по векторам vx, vy, vz их собственных движений с экстраполяцией в прошлое и будущее на шкале -10; 0; +10 Gyr;
- полиэдральные диаграммы Вороного GalaxyVoronoi, мозаики со звёздами в центральных узлах ячеек, рассчитываются как двойственные графы тетраэдрализации Делоне;
- построение регулярных моделей GalaxyGrid на униформных решётках выполняется по методу NNI, Natural Neighbour Interpolation с учётом влияния в интерполянте астрохарактеристик соседних регионов, за исключением областей войдов GalaxyVoids;
- формирование строения Галактики моделируется на базе подходов N-body, гравитационно взаимодействующих партикулярных кластеров и волновых функций;
- трансформация звёздных популяций имитируется на основе стохастических функций свёртки рождения и гибели звёзд основных спектральных классов согласно диаграмме Герцшпрунга-Рассела;
- при моделировании коэволюции скоплений звёзд с планетами применяются операция свёртки, стохастической конволюции спектральных классов звёзд; 
- задачи поиска кратчайшего, наиболее безопасного межзвёздного пути, задачи коммивояжера, освоения ресурсов и колонизации решаются на 5D графах (x,y,z,t,c) тетрасети и по алгоритму A* на регулярной решетке GalaxyGrid; 
- для астромодели GalaxyGrid прогнозируется число литосфер, биосфер и техносфер на базе данных обновляемых звёздных каталогов;
- оценка потенциала обитаемости Галактики выполняется по диаграмме Вороного 4D и сравнивается с оценкой по эмпирической формуле Дрейка;
- численное решение парадокса Ферми-Циолковского в GalaxyGrid предполагает вероятность существования ВЦ I и II типов по шкале академика РАН Н.С.Кардашёва;
- состав невидимой части Галактики за плотными облаками рукавов и ядром прогнозируется исходя из анализа структуры GalaxyCETI;  
- навигация по модели UniverseCETI может быть выполнена в VR/AR между скоплениями галактик и процедурно генерируемыми космическими объектами.
