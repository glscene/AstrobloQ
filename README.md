# GalabloQ

Репозиторий включает проекты:

Geosfera –  геосфера планеты, включая литосферу, гидросферу и атмосферу

Biosfera – биосфера планеты с организмами 

Noosfera – ноосфера планеты с техносферой цивилизации 

PlotStars - графики y=f(x), z = f(x,y) и g=(x,y,z)

WebGalaxy – построение сетки обитаемости и интерполяционной решетки Млечного Пути
