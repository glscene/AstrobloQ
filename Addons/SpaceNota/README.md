# SoaceNota

Аудио-визуальное воспроизведение космических небесных тел и их спектральных характеристик  
основано на графическом движке [GaLaXy Engine](https://gitverse.ru/glscene/GLXEngine/) с поддержкой OpenGL, Directx и Vulkan. 
При отображении небосвод SkyDome окрашивается в соответствии с сонохроматической шкалой, в диапазоне слышимого звука
нотами озвучиваются небесные тела, звёзды, линии и фигуры 88-ти созвездий.
Интерактивная справка связывает интерфейс с соответствующими статьями российской 
онлайн-энциклопедии Рувики.
