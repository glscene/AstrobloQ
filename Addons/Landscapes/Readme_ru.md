## LandScapes
  Этот пакет содержит четыре программы, демонстрирующие использование модуля GLS.RandomHDS.
Они расположены в пронумерованных папках, и для более быстрого освоения
следует изучать их в указанном порядке.

## LandscapeTutorial
********************
  Эта демонстрация показывает минимальные требования для использования TGLFractalHDS.
Также показано, как настроить GLScene для быстрой работы.
Эта демонстрация отображает циклический фрактальный ландшафт, используя
встроенный обработчик событий земного покрова (внешние текстуры не требуются).
Эта демонстрация может быть использована в качестве основы для любой программы, использующей этот объект.

##  FractalLandscape
*******************
 Эта программа демонстрирует практически все свойства GLS.RandomHDS.
Вы можете экспериментировать с ними через удобный интерфейс.
Это позволит вам быстро получить интуитивное понимание того, что
контролирует каждое свойство.

## DuneFighter
***************
  Эта простая демонстрация основана на демонстрации ActorTwoCams.
Она просто показывает, как циклический TGLFractalHDS можно использовать в игре с актёрами.

## FractalArchipelago
*********************
 Демонстрация демонстрирует, как можно генерировать GLS.RandomHDS «на лету»
с помощью компонента TGLFractalArchipelago.
Прежде чем приступить к работе с TGLFractalHDS, вам следует разобраться в его свойствах и методах.
